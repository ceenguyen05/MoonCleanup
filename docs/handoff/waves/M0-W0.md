## 3. Environment rules (every agent in this wave — read before running any command)

1. **Machine.** Windows 11. Two shells: PowerShell 5.1 (no `&&` / `||`; chain with `;`) and Git Bash. Shell state (variables, `cd`) does not persist between tool calls. The repo root is the working directory.
2. **Node version — mandatory prefix.** Agent tool shells do **not** load Cee's PowerShell profile, so a plain `node` is the system Node **v22.20.0** (`C:\Program Files\nodejs`). The project requires **Node 26.13.1** (`.nvmrc`, `engines.node` = `26.x`), installed through fnm. Start **every command line** that runs `node`, `pnpm`, `tsc`, `vitest`, `eslint`, `prettier`, `turbo` or `playwright` with this prefix:
   - PowerShell: `$env:PATH = "$env:APPDATA\fnm\aliases\default;$env:PATH"; $env:DO_NOT_TRACK = "1"; node -v; <your command>`
   - Git Bash: `export PATH="$(cygpath -u "$APPDATA")/fnm/aliases/default:$PATH" DO_NOT_TRACK=1; node -v; <your command>`

   `node -v` must print `v26.13.1` (verified by the lead on 2026-11-12; `pnpm -v` prints `11.28.9`, a global shim that runs on whichever `node` is first on PATH). If it prints anything else, stop and report. Never install, switch or remove Node versions, and never change Cee's profile, registry or PATH permanently.
   **Exception:** Claude Code *hooks* are started by the harness with its own `node` (today the system v22.20.0). See the T04 brief.
3. **Git.** No git command that changes state, ever. Read-only `git status | diff | log | show | rev-parse | ls-files` is allowed and rarely needed.
4. **Permission prompts.** Background agents cannot answer prompts; Cee approves them in the main session. Keep each command plain and single-purpose so it is easy to approve. If a command is denied, do not retry it in another form: note it in your report and continue with what is safe.
5. **Downloads.** Fetch files as exact bytes with `curl -fsSL "<url>" -o "<path>"`. Never paste `WebFetch` output into a source or vendored file (it is a model-processed rendering, not the original). `WebFetch` / `WebSearch` are for finding URLs and reading documentation only.
6. **Privacy.** Never send the project name, the repo URL, Cee's name or e-mail to an outside service (search queries, issue trackers, pastebins).
7. **Ports.** No dev server is needed in this wave. If you start one anyway, use your port offset `N` (client `5173+N`, server `2567+N`).
8. **Recovery.** Checkpoint files/results/Next and actual agent IDs at coherent deliverables or interruptions; no per-task report is mandatory.
