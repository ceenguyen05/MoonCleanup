## Non-blocking findings
1. **The override relies on hoisting and an API gap (functional risk).** The transport was written against uWS 20.52 and now loads 20.71 through pnpm's hidden hoist. Fix: the T03 server boot test should import `@colyseus/uwebsockets-transport` and open a socket. Never set `hoist: false` or narrow `hoistPattern` without revisiting this. Optional: pin the manifest to the commit (`#9ec36de…`) so a re-pointed tag cannot change a non-frozen re-resolve.
2. **Two `@colyseus/schema` versions.** The server pins 5.0.48. `@colyseus/sdk@0.18.10` pulls 5.0.47 (lockfile line 3565), which the client and tests use. Encoder and decoder patch versions differ. Fix: the M1 protocol handshake test must cover a client-SDK-to-server schema round trip. Alternatively, align them with a scoped override once ADR/devops agree.
3. **Release-age excludes are acceptable.** They are exact `name@version` entries equal to the manifest pins (schema, turbo plus 6 platform binaries, prettier), all from official scopes, with no globs or name-only entries. Remove them once the versions have aged past the window, and never widen them to a name-only form.
4. **Unscoped `sentry@0.49.0`** comes from `@sentry/bundler-plugins@11.12.0`. Its repository is `getsentry/toolkit`, it has a `sentry` bin and no install hook, and it is build-time only (vite plugin). It looks legitimate. I note it because unscoped brand names are a common typosquat pattern, so re-check it on Sentry upgrades.
5. **Platform-only optional packages were not scanned on disk** (Windows host): `fsevents`, Linux `@img/*`, `lightningcss-*`, `@esbuild/*`, `@rolldown/*`, `@turbo/*`, `@oxc-parser/*`. If any of them carries a script, pnpm 11 fails closed (`ERR_PNPM_IGNORED_BUILDS`), so that case is safe. The first Linux CI or Render install confirms there is no surprise.
