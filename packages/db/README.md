# @moon-cleanup/db

**Path:** `packages/db` - **Owner role:** `backend-data-engineer` - **Layer:** persistence (server-only)

## Purpose

Drizzle ORM schema, generated SQL migrations and repositories for **Aiven for PostgreSQL Free** (1 CPU, 1 GB RAM,
**1 GB storage**, powers off when idle). Tables cover guests/accounts, hashed refresh tokens, profiles, contracts and
save blobs. Migrations are generated by `drizzle-kit`, reviewed in PR and **applied in the Render build command**
(`render.yaml` runs `pnpm --filter @moon-cleanup/db run migrate`; `preDeployCommand` is paid-only).

## What Fable will build here

`src/schema/` (Drizzle table definitions), `src/repositories/` (typed queries), `migrations/` (generated SQL, committed),
a `drizzle.config` and a `migrate` runner that reads `DATABASE_URL` and `DATABASE_CA_CERT` (TLS with the Aiven CA, see
`apps/server/.env.example`), and the `src/index.ts` barrel.

## Key contracts consumed (from `@moon-cleanup/shared`)

IDs & units, REST DTOs (`api/rest`), save format (`save/format`, `SAVE_FORMAT_VERSION`).

## Rules

- Imported only by `apps/server`. `apps/client` never imports this package.
- Drivers: `drizzle-orm` 0.45.4 + `postgres` (postgres.js) 4.1.1, `drizzle-kit` 0.31.11. Drizzle 1.0 is in RC: a major
  migration needs an ADR (Dependabot ignores `drizzle-*` majors).
- Free tier has no connection pooling and a 1 GB cap: keep writes coalesced and rows small.

## Commands

```
pnpm --filter @moon-cleanup/db generate   # placeholder -> drizzle-kit generate
pnpm --filter @moon-cleanup/db migrate    # placeholder -> drizzle-kit migrate (used by render.yaml)
pnpm --filter @moon-cleanup/db test
```

`generate`, `migrate`, `lint` and `typecheck` are echo placeholders so the Render build command and CI do not fail on an
empty repo; Fable replaces them when the schema exists.
